## Performance interpretation and limitations

The authority harness sustains 24 mixed living zombies for 310 simulated seconds, with two moving players, attacks, shooting and JSON snapshots. The final run measured 9,000 ticks: 2.49 ms mean, 4.41 ms p95, 8.80 ms p99, 86.72 ms max; 5 ticks exceeded the 33.33 ms budget, never more than 2 consecutively. AI averaged 1.83 ms (3.34 ms p95), navigation 0.20 ms (0.61 ms p95), with at most 2 paths/tick, 13,390 paths, zero failed paths/spawns, 8,814-byte max snapshot, ~117 KB/s and 30.3 messages/s per client. Heap stayed 17.72–18.19 MB after forced GC. The harness restores test health/ammunition and replaces enemies. Timing includes authority input/combat/simulation/serialization; replacement setup is outside the measured tick. It is an offline simulation benchmark, not a wall-clock scheduling or GPU guarantee. Memory samples force GC and are limited to this workload/duration.

Before render batching, the warmed 24-zombie 1080p browser capture measured 44 FPS / 22.9 ms, 207 draws, 41 ms ping, 68 ms snapshot age, 5.87 ms server tick, 3.76 ms AI, zero failed paths/spawns and zero zombie corrections. After the final batching build, the same two-client 1080p capture measured 602 frames over 10.00 seconds (60.2 FPS), 16.62 ms mean frame time, 17.10 ms p95, 17.60 ms max, 68 draw calls, 20 ms ping and 25 ms snapshot age. HUD server tick was 7.02 ms with 3.83 ms AI, 0.05 ms navigation, zero failed paths/spawns and zero zombie corrections. Chrome reported the AMD Radeon Vega 8 renderer. Earlier overloaded captures were 14–16 FPS and showed stalls and input-rate warnings. The cap remains 24; it was not silently reduced.

Development diagnostics' drift value is cumulative dropped scheduling time for the process, including cold compilation and shared-machine contention. It is not a per-frame or isolated-match drift sample. The external production server should run separately from Next compilation and browser GPU work.

No sustained 1080p/60 FPS claim or long-duration client memory certification is made. Profile on the intended production runtime and representative desktop hardware. Network payloads remain bounded JSON and can benefit from future compact encoding. Temporary geometry/audio, static-grid navigation for this one arena, one persistent process, and loss of live runs on process restart remain documented limits. Future authored art, navigation backends and replication encoding can use the existing boundaries; no future shop, weapon, economy, objective, boss or progression feature is implemented.
