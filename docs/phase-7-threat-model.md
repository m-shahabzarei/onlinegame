# Phase 7 threat model

| Asset / actor                            | Attack surface and impact                                              | Existing and required mitigation                                                                                   | Detection / recovery                                                             | Residual risk                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Accounts and sessions / remote attacker  | Credential stuffing, cookie theft, takeover                            | Password hashing, opaque HTTP-only SameSite cookies, expiry, logout revocation, generic protected-route errors     | Auth failures and rate-limit events; revoke session and rotate credentials       | Browser malware remains outside the app boundary                          |
| Guest identity / client                  | Spoofed user id or horizontal profile mutation                         | Server-resolved session identity; authorization checks; bounded guest lifetime                                     | Structured auth errors; expire and clean unreferenced guests                     | Guest users are intentionally low assurance                               |
| Rooms and invite links / enumerator      | Code guessing and private-room access                                  | Bounded codes, membership authorization, generic lookup errors, identity/network limits                            | Lookup/join rejection counters; close expired rooms                              | A public room can be discovered by design                                 |
| Join tickets / replay attacker           | Token replay, wrong match/slot/version                                 | HMAC signature, audience, match/slot/runtime checks, short expiry, replay guard                                    | `TOKEN_USED`, `TOKEN_EXPIRED`; restart match lease                               | In-memory replay state resets on process restart; tickets are short lived |
| Gameplay WebSocket / abusive client      | Payload floods, fake movement/damage/Scrap/boss state, origin spoofing | Explicit origins, 4 KiB frames, strict versioned schemas, command budgets, server-owned simulation/economy         | Rejected-command diagnostics, disconnect slow/abusive peers, match-local failure | No commercial anti-cheat; signals require operator review                 |
| Database / concurrent requests           | Duplicate purchase, stale room writes, partial outcome                 | Prisma transactions, unique keys, state/revision checks and idempotency receipts                                   | Transaction/error logs; retry safe operation or reconcile                        | External database outage needs operator restoration                       |
| Realtime provider / outage               | Presence and lobby availability                                        | Provider boundary, Redis timeouts, readiness semantics, reconnect refresh                                          | Provider failure metrics; degrade lobby and retry                                | Provider regional outage                                                  |
| Web/game server / DoS                    | Capacity exhaustion, event-loop starvation                             | Match/player/entity/queue bounds, backpressure, readiness and graceful shutdown                                    | Tick drift, queue, CPU/memory and capacity signals; drain/restart                | Network-layer attacks need upstream controls                              |
| Logs and observability / malicious input | Log injection or secret/PII leakage                                    | JSON logger redacts credential-like keys and strips control characters                                             | Secret scan and log review                                                       | New fields must use logger/redaction policy                               |
| HTTP/browser / cross-site attacker       | CSRF, clickjacking, XSS, unsafe redirects, SSRF                        | Origin checks, JSON/content limits, CSP, HSTS, frame policy, safe internal redirects; no server URL fetch endpoint | Security-header tests and 4xx metrics                                            | Third-party browser extensions remain out of scope                        |
| Dependencies/assets / supply chain       | Vulnerable package or untrusted script                                 | Locked versions, no remote CDN game assets, npm audit review, CSP                                                  | Dependency audit and release gate                                                | Accepted advisories are documented per release                            |

No player-facing moderation, bans, chat, voice or social systems are introduced in this phase.
